  Concepts : Utilisation du mot-clé static.
  Réponse à la question : La méthode de classe (static) est préférable pour la division car c'est une opération utilitaire qui ne dépend pas de l'état d'un objet spécifique.
  Fichiers : Division.java, TestDivision.java.
- **Exo_diapo_38 :** Concepts : Protection des données avec l'attribut private et accès via des méthodes publiques (Getters/Setters).
 Fichiers : Voiture.java, TestVoiture.java.

 Fichiers : Vehicule.java, Train.java, Bateau.java, VoitureCarburant.java.
