# Description du TP_0_ICT207_DOUNTIO_24H2209

**Prénom :** SERENA

## Description des devoirs
- **Exo_diapo_23,24 :**  Gestion des Points 
  Concepts : Constructeurs (par défaut, avec paramètres, par copie), méthodes d'instance et calculs mathématiques.
  Fichiers : Point.java, TestPoint.java.
- **Exo_diapo_34 :** Méthodes de Classe vs Instance 
  Concepts : Utilisation du mot-clé static.
  Réponse à la question : La méthode de classe (static) est préférable pour la division car c'est une opération utilitaire qui ne dépend pas de l'état d'un objet spécifique.
  Fichiers : Division.java, TestDivision.java.
- **Exo_diapo_38 :** Concepts : Protection des données avec l'attribut private et accès via des méthodes publiques (Getters/Setters).
 Fichiers : Voiture.java, TestVoiture.java.
- **Exo_diapo_53 :**
  Concepts : Extension d'une classe parente (extends) et utilisation de super() pour les constructeurs.
  Fichiers : VoitureElectrique.java.
- **Exo_diapo_55 et 56 :**   Concepts : Redéfinition de méthodes (Overriding) et comportement dynamique des objets.
 Fichiers : Vehicule.java, Train.java, Bateau.java, VoitureCarburant.java.


Ce dépôt contient les solutions aux exercices pratiques du cours de POO en Java, couvrant les concepts fondamentaux de la manipulation des classes jusqu'au polymorphisme.
